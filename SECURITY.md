# Security Policy

Aggregation can amplify coordinated or correlated misinformation if source independence is assumed without evidence.

- Treat source IDs as identifiers, not proof of independent ownership.
- Preserve source provenance and possible shared upstream dependencies.
- Never convert quorum into a truth label or automated enforcement action.
- Keep dissent and minority observations visible.
- Rate limits, authentication, and Sybil resistance belong in the deployment layer.

Report vulnerabilities with affected revision and a minimal reproduction. Avoid disclosing private source identities.
